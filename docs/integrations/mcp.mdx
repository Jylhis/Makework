The `mw ai init` command outputs a
[Claude Code skill](https://docs.anthropic.com/en/docs/claude-code/skills)
definition that teaches Claude Code how to navigate your repos, manage the
catalog, and run cross-project operations — without parsing shell output.

## Install the skill

```sh
mw ai init > .claude/skills/makework.md
```

Claude Code automatically picks up skills from `.claude/skills/`. Place it
in the project root or your home directory depending on whether you want
it scoped to one repo or available globally.

## What the skill provides

The skill is a structured prompt that describes all `mw` commands:

| Operation         | Command                          | Description                              |
|-------------------|----------------------------------|------------------------------------------|
| Navigate          | `mw go <query>`                  | Fuzzy-match a project and cd into it     |
| Create worktree   | `mw new <project> <ref>`         | Create a new worktree for a branch       |
| Remove worktree   | `mw rm <project>/<ref>`          | Remove a worktree                        |
| List worktrees    | `mw ls`                          | Show all active worktrees                |
| Sync repos        | `mw sync`                        | Discover and register repos from scan roots |
| Fetch updates     | `mw fetch [project]`             | Fetch all or specific repos              |
| Catalog add       | `mw catalog add <path\|url>`     | Register a repo by path or URL           |
| Catalog list      | `mw catalog list`                | Show all registered repos                |
| Status            | `mw status`                      | Worktree overview (branch, dirty, ahead/behind) |
| Search            | `mw search <pattern>`            | Grep across all worktrees                |

## Regenerate after updates

If you update `mw` to a new version, regenerate the skill to pick up any
new commands:

```sh
mw ai init > .claude/skills/makework.md
```

## Example session

```text
> claude: which repos are registered?
[runs mw catalog list]
You have 7 repositories registered: ...

> claude: navigate to the auth service
[runs mw go auth-service]
Checked out main at ~/Developer/.../auth-service/main
```
