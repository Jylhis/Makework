Makework is built with Nix via [devenv](https://devenv.sh) and
[crate2nix](https://github.com/nix-community/crate2nix). The repository
contains a `devenv.nix` that drives local development and produces a Nix
package as a devenv output.

## devenv.nix (development)

Entering the dev shell gives you everything needed to build, test, and lint
the workspace:

```sh
devenv shell
```

Inside the shell:

```sh
cargo build
cargo test
cargo clippy --all-targets -- -D warnings
cargo mutants    # mutation testing
treefmt          # format Rust + Nix files
```

The shell also enables Claude Code's MCP server for devenv, so AI assistants
can introspect the dev environment.

## Building with crate2nix

`devenv.nix` defines a `makework` output built via `crate2nix`, which
converts the Cargo workspace into a pure Nix derivation tree. No internet
access at build time.

The built package is exposed through devenv's `outputs` mechanism:

```nix
outputs = {
  inherit makework;  # cargoNix.workspaceMembers.mw-cli.build
};
```

## Binary caching

The devenv configuration pulls prebuilt artifacts from the `jylhis` Cachix
cache. Pushing is opt-in via `devenv.local.nix` or by setting
`CACHIX_AUTH_TOKEN` in CI.
