Makework is a command-line tool for developers who juggle many repositories
and branches. It clones each repository once as a bare repo, then creates one
worktree per branch you check out — so switching between projects never
disturbs work in progress.

## What you get

## Try it

```sh
mw catalog add ~/Developer/myrepo  # register a repo
mw go myrepo                       # cd into a worktree
mw go feat@new-ui                  # fuzzy match + branch routing
mw                                 # status across all worktrees
```
