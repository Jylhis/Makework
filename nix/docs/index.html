makework

Opinionated git worktree manager.

This site documents the programs.makework option set exposed by each module variant. Pick the context that matches how you consume the flake.

  • home-manager — per-user install, config.toml, shell hook
  • NixOS — system-wide install, shell hook on /etc/bashrc & /etc/zshrc
  • nix-darwin — macOS equivalent of the NixOS module
  • nix-on-droid — Android install (use home-manager inside for config/hook)

Flake wiring

inputs.makework.url = "github:jylhis/makework";

# NixOS host
imports = [ inputs.makework.nixosModules.default ];
programs.makework.enable = true;

# home-manager
home.sharedModules = [ inputs.makework.homeManagerModules.default ];
programs.makework = {
  enable = true;
  settings.worktree_root = "/home/alice/code/worktrees";
};
